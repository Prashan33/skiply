## Prompt

> make sure that the courses on the homepage are also being fetched from the
> seeded sanity content

## Goal

Replace the hardcoded `courses` array in `app/page.tsx` with the seeded Sanity
catalog, rendered through the existing `CourseCard`, keeping the homepage design
unchanged.

## Code inspected

- `app/page.tsx` — homepage. Static `courses` array of 3 items drives the
  "All Courses" grid via `CourseCard`. Also has a hardcoded hero and a
  `SkylineDecoration`. Only the grid changes.
- `sanity/lib/queries.ts` — `CATALOG_COURSES_QUERY` already exists (ordered
  `popular desc, title asc`) and returns `_id, title, slug, summary, level,
  price, popular, studentCount, coverImage, instructor, category, moduleCount,
  lessonCount`. **No total course duration.**
- `sanity.types.ts` — `CATALOG_COURSES_QUERY_RESULT` generated; all scalars
  nullable.
- `components/ui/Card.tsx` — `CourseCard` needs `icon`, `iconClassName?`,
  `title`, `description`, `level`, `duration`, `modules` (all strings /
  ReactNode). It is presentational, no link.
- `app/courses/[slug]/page.tsx` (just added) — reads the private dataset with
  `getReadClient().fetch(query, params, { next: { revalidate, tags }})` because
  `defineLive`'s `sanityFetch` does not send the token for published reads.
  Uses a monogram tile derived from the title. `lib/format.ts` has
  `formatDurationFromSeconds` and `capitalize`.

## Decisions & assumptions

1. **Add total duration to `CATALOG_COURSES_QUERY`** so the card's `duration`
   line stays populated:
   `"durationSeconds": math::sum(modules[].lessons[]->duration)`.
   Re-run `npm run typegen`. This is the only query edit.
2. **Fetch in `app/page.tsx`** (make the component `async`): use the same
   `getReadClient().fetch(CATALOG_COURSES_QUERY, {}, { next: { revalidate: 60,
   tags: ["course"] }})` pattern as the course page. No `sanityFetch` (can't
   read the private dataset for published content).
3. **Card mapping:**
   - `icon`: monogram — the title's first letter in `font-display` — matching
     the course page hero and the current homepage's Next.js card.
   - `iconClassName`: `bg-neutral-900 text-white` for every card (consistent;
     the seed has no per-course brand color, and the design's varied colors were
     mock-only). Keep it simple and uniform.
   - `title`: `title`.
   - `description`: `summary` (fallback `""`).
   - `level`: `capitalize(level)` (fallback `""` — card still renders).
   - `duration`: `formatDurationFromSeconds(durationSeconds)`.
   - `modules`: `${moduleCount ?? 0} modules`.
   - React key: `_id`.
4. **Wrap each card in a `Link`** to `/courses/${slug}` when `slug` is present
   (the cards are currently dead; the course page now exists, so linking is the
   natural, non-overbuilt step). Skip the link if `slug` is null.
5. Show all seeded courses (10), not a slice — the section header is
   "All Courses". The "View all courses" link stays as-is (`href="#"`).
6. Hero, search input, and `SkylineDecoration` are unchanged. Empty result →
   render the section with no cards (no crash); acceptable, seed has data.
7. Homepage becomes dynamic (`ƒ`) for the same private-token reason as the
   course page. Acceptable.
